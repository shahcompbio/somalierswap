# shahcompbio/somalierswap: Output

## Introduction

This document describes the output produced by the pipeline. The MultiQC report summarises somalier relatedness results across all samples at the end of the pipeline.

The directories listed below will be created in the results directory after the pipeline has finished. All paths are relative to the top-level results directory.

## Pipeline overview

The pipeline is built using [Nextflow](https://www.nextflow.io/) and processes data using the following steps:

- [somalier extract](#somalier-extract) - Extract fingerprint sites from BAM files
- [somalier relate](#somalier-relate) - Compute pairwise relatedness within subject groups
- [MultiQC](#multiqc) - Aggregate relatedness report
- [Pipeline information](#pipeline-information) - Report metrics generated during the workflow execution

### somalier extract

<details markdown="1">
<summary>Output files</summary>

- `somalier/extract/`
  - `*.somalier`: Binary fingerprint file for each sample, containing genotype likelihoods at the somalier sites.

</details>

[somalier extract](https://github.com/brentp/somalier) processes each input BAM file, extracting read information at a set of known polymorphic sites. The resulting `.somalier` files are compact binary fingerprints used downstream for relatedness calculations.

### somalier relate

<details markdown="1">
<summary>Output files</summary>

- `somalier/relate/`
  - `*.pairs.tsv`: Pairwise relatedness statistics for every pair of samples within the subject group.
  - `*.samples.tsv`: Per-sample statistics including inferred sex and ancestry.

</details>

[somalier relate](https://github.com/brentp/somalier) computes pairwise relatedness (IBS0, IBS2, kinship coefficient) between samples. By default, samples are grouped by subject and compared within each group. When `--cohort` is used, all samples are compared together as a single cohort. High kinship between samples expected to be unrelated — or low kinship between samples expected to be related — indicates a potential sample swap. The `pairs.tsv` output is used as input to MultiQC.

Key columns in `pairs.tsv`:

| Column                 | Description                                                                  |
| ---------------------- | ---------------------------------------------------------------------------- |
| `sample_a`, `sample_b` | Sample identifiers being compared                                            |
| `relatedness`          | Estimated kinship coefficient (0 = unrelated, 0.5 = identical/duplicate)     |
| `ibs0`                 | IBS0 count (sites where samples share 0 alleles — high values indicate swap) |
| `ibs2`                 | IBS2 count (sites where samples share both alleles)                          |
| `expected_relatedness` | Expected relatedness from pedigree (if provided)                             |

### MultiQC

<details markdown="1">
<summary>Output files</summary>

- `multiqc/`
  - `multiqc_report.html`: Standalone HTML report summarising somalier relatedness results for all samples.
  - `multiqc_data/`: Directory containing parsed statistics.
  - `multiqc_plots/`: Static images from the report.

</details>

[MultiQC](http://multiqc.info) generates a single HTML report visualising the somalier relatedness results across all subject groups. The report includes relatedness heatmaps and flagged sample pairs with unexpected relatedness values.

### Pipeline information

<details markdown="1">
<summary>Output files</summary>

- `pipeline_info/`
  - Reports generated by Nextflow: `execution_report.html`, `execution_timeline.html`, `execution_trace.txt` and `pipeline_dag.html`.
  - `somalierswap_software_mqc_versions.yml`: Software versions used in the pipeline run.
  - Parameters used by the pipeline run: `params.json`.

</details>

[Nextflow](https://www.nextflow.io/docs/latest/tracing.html) provides excellent functionality for generating various reports relevant to the running and execution of the pipeline. This will allow you to troubleshoot errors with the running of the pipeline, and also provide you with other information such as launch commands, run times and resource usage.
